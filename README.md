# 📝 文字数カウンター / Text Count Tool

テキストを入力するだけでリアルタイムに文字数を計測できる、シンプルで高機能な文字数カウンターです。

A simple yet powerful real-time character counter tool. Just type or paste your text to instantly see detailed character counts.

---

## ✨ 機能 / Features

| 項目 | 説明 | Description |
| ------ | ------ | ------------- |
| 文字数（空白込み） | スペース・タブを含む全文字数 | Chars including spaces |
| 文字数（空白抜き） | スペース・タブを除いた文字数 | Chars excluding spaces |
| 文字数（改行・空白抜き） | 改行・スペース・タブを除いた文字数 | Chars excluding spaces & newlines |
| 文字数（半角0.5文字換算） | 半角を0.5として計算した文字数 | Chars with half-width counted as 0.5 |
| 空白の数 | スペース・タブの総数 | Total space/tab count |
| 行数 | 改行で区切られた行の数 | Number of lines |
| 段落数 | 空行で区切られた段落の数 | Number of paragraphs |
| 文字数内訳 | 全角・半角それぞれの文字数 | Full-width / half-width breakdown |

### その他の機能 / Additional Features

- ⚡ **リアルタイム集計** — 入力のたびに即時更新 / Instant update on every keystroke
- 📋 **クリックでコピー** — 数値をクリックするとクリップボードにコピー / Click any number to copy
- ⚙️ **カウント条件カスタマイズ** — 除外する文字種を細かく設定（再読み込み後も保持） / Customize what to exclude (settings saved across reloads)
- 🌐 **日英バイリンガルUI** — 日本語と英語で表示 / Bilingual Japanese & English interface

---

## 🛠️ 使い方 / Usage

1. テキストエリアにカウントしたい文章を入力・貼り付けする
2. リアルタイムで各種カウントが表示される
3. 数値をクリックするとその値がクリップボードにコピーされる
4. 「カウント条件カスタマイズ」を開くと、除外する文字種を細かく設定できる

---

1. Type or paste your text into the textarea.
2. Character counts update in real time.
3. Click any number to copy it to your clipboard.
4. Open "Customize Count Options" to fine-tune what characters to exclude.
